# doc-scan-exclusions

## Purpose

SSoT for the exclusion pattern list used when Grep-collecting frontmatter-based documents (`type: project` / `type: steering`) across the entire repository. Consolidates the pattern list that was previously copied inline into three separate call sites, so that adding or changing an exclusion item requires editing only this file.

## Processing Steps

When collecting candidate files via a `type: project\|type: steering` (or `type: project`-only, depending on the caller) Grep pattern limited to `*.md` files, skip files matching these exclusion patterns:

- Paths starting with `$SPEC_PATH/` (specification documents)
- Paths containing `node_modules/` (external dependencies)
- Paths starting with `.git/` (Git management files)
- Paths starting with `.tmp/` (temporary files)
- Translation output: paths under `docs/{lang}/` (language-code-named directories under `docs/`), and `README.{lang}.md` at the project root (generated by `/doc translate {lang}`)

After path-based exclusion, apply a content-level check to each remaining candidate file to
distinguish a real frontmatter occurrence from a template/example occurrence quoted inside a
**fenced code block** (```` ```...``` ````): a skill or module file (e.g. `skills/doc/SKILL.md`)
may show `type: project` / `type: steering` as sample YAML inside a fenced code block when
documenting how to author frontmatter — that fenced-block text is not the file's own frontmatter
and must not make the file itself a candidate.

- A file's real frontmatter is the YAML block delimited by a `---` line at the very start of the
  file and the next `---` line. Extract that block (e.g. `sed -n '/^---$/,/^---$/p'` applied to
  the first match only, or read the first lines up to the second `---`) and re-check the
  `type: project\|type: steering` pattern against it alone.
- If the pattern matches inside that leading frontmatter block, keep the file as a candidate.
- If the file's grep hit falls outside the leading frontmatter block (including inside a fenced
  code block anywhere in the body), exclude the file — the match is a template/example, not the
  file's own frontmatter.
